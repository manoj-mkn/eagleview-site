Phase 4 · Corporate IT Deployment
Enterprise-Grade Installation
IT departments will not adopt software they cannot centrally deploy and manage
0 / 8
▼
Installer Requirements
Code-sign the Mac app with Apple Developer Certificate
Unsigned apps show "untrusted developer" warning — IT blocks them. Certificate costs ~$99/year
ENTERPRISE
Notarise the Mac app with Apple Notary Service
macOS Gatekeeper requires notarisation — without it the app cannot run on modern Macs
ENTERPRISE
Code-sign the Windows EXE with a Code Signing Certificate
Unsigned EXEs trigger Windows Defender SmartScreen warning — IT will reject it
ENTERPRISE
MSI package for Windows (silent install via Group Policy)
IT deploys MSI to 1000 machines in minutes — NSIS EXE cannot be pushed via Intune/SCCM
ENTERPRISE
Auto-Update
Auto-update via electron-updater pointing to GitHub Releases
App checks for new version on startup and updates silently — no user action needed
DEV
IT admin can disable auto-update via config file
Some companies control all software updates centrally and need to turn off auto-update
ENTERPRISE
MDM / Intune Support
App listed in Microsoft Intune / JAMF as deployable package
IT admins can deploy Eagle View to all company machines with one click
ENTERPRISE
Admin config file support (JSON) — pre-configure settings for all users
IT sets default refresh intervals, branding, and feature flags before deploying
ENTERPRISE
