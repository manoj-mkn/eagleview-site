Phase 2 · IT & Security Setup
Get IT On Board
Address every question your IT department will ask — before they ask it
0 / 8
▼
Authentication
Register Eagle View in your company's Azure Active Directory
IT admin registers the app under your tenant so work accounts (@yourcompany.com) can log in
IT
Grant Admin Consent for the required Microsoft Graph API permissions
Permissions needed: User.Read, Mail.Read, Calendars.Read — read-only, no write access ever requested
IT
Confirm all 100 employees can log in with company SSO credentials
Test with 5 accounts across different AD groups — confirm no login errors
CHECK
Security Review
Confirm data flow: Microsoft → App only — no data sent to external servers
Eagle View is local-first; API calls go directly from the desktop app to Microsoft — no intermediary server
IT
Review what is stored locally on the employee's machine
Token cache, notes, display preferences only — no email content is ever written to disk
IT
Run npm audit on the app package — confirm no critical CVEs
Share audit report with IT if required — shows due diligence on dependency security
IT
Deployment
Test silent install on a Windows machine via Intune or manual EXE push
For 100 people, silent deployment saves hours vs asking each employee to install manually
IT
Test Mac deployment via JAMF or manual DMG push
Confirm the DMG installs to /Applications with no Gatekeeper errors for all macOS versions in use
IT

Phase 3 · Configuration & Branding
Make It Feel Like Home
Tailor Eagle View to your company's tools, colours, and workflows before the full rollout
0 / 7
▼
Visual Identity
Choose a colour theme that aligns with your company brand
Eagle View ships with 5 themes: Siemens, Ocean, Forest, Ember, Classic — pick the closest match
CONFIG
Confirm the app's default theme is set in the rollout package
Set the localStorage default so all employees see the chosen theme on first launch
CONFIG
Row Configuration
Decide which rows are relevant to your company and hide the rest
Example: a 100-person tech company may want Jira + Mails + Meetings but hide Peakon or Timesheet
CONFIG
Set the default row order that makes sense for your team's workflow
Most-used rows at the top: typically Mails → Meetings → Jira for most tech teams
CONFIG
Set sensible refresh intervals for each live row
Mails: 1m, Meetings: 5m, Jira: 10m — avoid very short intervals that hit API rate limits
CONFIG
World Clock
Set the two world clock timezones to your company's most-used locations
For example: HQ timezone + main overseas office timezone — saves everyone from Googling "what time is it in Munich?"
CONFIG
Document the recommended default settings in an internal wiki page
New joiners should be able to configure Eagle View in under 5 minutes by reading one page

Phase 4 · Company-Wide Rollout
Deploy to All 100 Employees
A structured rollout prevents confusion and ensures everyone is set up correctly on day one
0 / 9
▼
Pre-Launch
Send a company announcement email 3 days before launch
"Eagle View is coming to your desktop on [date] — here's what it does and why you'll love it"
NOW
Prepare a 1-page "Getting Started" PDF or wiki page
Cover: what it is, how to open it (⌘+E), how to log in, how to customise. No longer than one page
TRAIN
IT pushes the installer to all Windows machines via Intune/SCCM
Silent install flag ensures no popups or confirmations required on employee machines
IT
Mac users receive a link to download the DMG or are notified via JAMF
If JAMF is not available, a Slack message with the direct download link works for a 100-person company
IT
Launch Day
Run a 20-minute all-hands demo call on launch day
Live demo: show the widget opening, mail count, meeting countdown joining — takes 5 minutes, answers 90% of questions
TRAIN
Designate one "Eagle View champion" per team (3–5 people total)
Champions are the first port of call for questions — reduces IT helpdesk load immediately
ADOPT
Post-Launch
Collect adoption metrics at end of week 1 (how many employees activated?)
Target: 70%+ employees logged in and using it within the first week — follow up with those who haven't
CHECK
Fix any login or display issues raised in the first 48 hours
The first 48 hours are critical — unresolved issues in week 1 cause permanent abandonment
IT
Send a "Tips & Tricks" email in week 2 to drive deeper engagement
Highlight: ⌘+E shortcut, drag-to-reorder rows, pin/lock feature, Notes section with reminders
TRAIN
